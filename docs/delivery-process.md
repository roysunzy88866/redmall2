## ✅ Definition of Done(DoD)

**切片"做完"= 同时满足以下 7 条**(任一不达即不算做完):

| # | 条件 | 不满足怎样 |
|---|---|---|
| 1 | 该切片所有**单元测试**绿(domain 100%, services ≥90%, repos ≥80%) | 不允许交付 |
| 2 | 该切片所有**集成测试**绿(每 endpoint 至少 1 happy + 1 error) | 不允许交付 |
| 3 | 该切片**端到端测试**覆盖核心 happy path | 不允许交付 |
| 4 | 相关文档**同提交**已同步(api.md / architecture.md / story-map / user-stories) | 不允许交付 |
| 5 | `docs/drift-log.md` **无未闭合条目** | 不允许交付 |
| 6 | 给用户**中文交付报告**(做了什么 + 测试结果 + 演示步骤) | 不允许交付 |
| 7 | 共识对账清单对应条目**已勾掉** | 不允许交付 |

**禁止的交付状态**:
- ❌ 测试失败(哪怕 1 条)
- ❌ 文档与代码不一致
- ❌ drift-log 有未闭合条目
- ❌ 业务逻辑藏在 view / Composable
- ❌ dict 渗入 service 或 domain 层
- ❌ TODO / FIXME 未带债务编号

## 🎬 交付动作的顺序

每个切片结束时:

```
1. 跑全部该切片测试 → 中文报告(见下方模板)
2. 跑全部回归(本片 + 之前所有片)→ 报告
3. 列演示步骤(3-5 步,用户可照着点)
4. 同提交同步所有相关文档(必须同 commit)
5. 共识对账清单勾对该切片对应条目
6. 提交 + 给用户交付报告

里程碑(M_n)结束时,额外:
7. 跑 M_1..M_n 全量回归(无回归才算 M_n 完成)
8. 给用户**完整演示**,用户明文「✅ 通过 M_n」 → 才进 M_{n+1}
```

### "前后对比"模板(涉及大改动时)

```
改动前:用户点商品 → 直接跳支付成功
改动后:用户点商品 → 弹二维码 → 点屏幕任意位置 → "支付成功" → 回首页

例子:
- 充电头(¥39)详情页 → 点下单
- 弹出全屏二维码 + "点击屏幕任意位置完成支付"
- 点任意空白 → 显示绿色对勾 + "支付成功"
- 1.5 秒后自动回到首页
- 后台「订单」页 F5 → 看到一条新订单
```

### 涉及钱 / 隐私 / 公网影响的提前告知

任何涉及以下,**先告诉用户后果再动**:
- API 调用费(LLM / SMS / 地图等)
- 订阅性服务
- 域名 / DNS 改动
- 上传文件大小限制改动
- 数据库 schema 大改

## 📋 共识对账流程

### 切片开工前

1. 翻 [需求共识.md](../需求共识.md),列出本片要触达的条款
2. 翻 [story-map.md](story-map.md),确认本片涉及的故事 ID
3. 写入切片标题:`C_n · <名称> [覆盖共识 §X.Y, §X.Z; 故事 US-ABC-NN, US-DEF-NN]`

### 切片结束前

1. 逐条 ✅ 勾对账清单
2. **未实现的共识条款** → 不能交付
3. **多实现了不在共识里的能力** → 不允许,落 [drift-log.md](drift-log.md)
4. 故事状态 ⏳ → ✅ 同提交更新 [story-map.md](story-map.md)

## 🆘 失败处理

| 场景 | 处理 |
|---|---|
| 测试反复失败 3 次 | 停,告诉用户原因(不是闷头改) |
| 共识冲突 | 立刻停 + 三选 + 用户拍板(参考 [CLAUDE.md §共识防漂移](../CLAUDE.md)) |
| 切片范围估错 | 拆切片或合并切片,记 [drift-log.md](drift-log.md) |
| 用户改需求 | 走「共识修改流程」:用户明文 + 改共识 + 同提交 ADR |
| 测试和实现都错 | 同时修两边 + drift-log 登记 + 给用户说明 |
| 演示被用户打回 | 不算 M_n 完成,定位是共识误读还是实现 bug,记 drift-log,修完重演 |

## 🔁 切片节奏速查

```
开工:对账共识 + 列故事 ID + 写 Gherkin 场景
↓
TDD: red(失败测试)→ green(最小实现)→ refactor
↓
逐函数单测 → endpoint 集成测试 → 切片末 E2E
↓
同提交同步文档(api / architecture / story-map / user-stories)
↓
跑全部测试 → 中文报告
↓
共识勾对账 → 给用户交付报告
↓
里程碑触发? → 全量回归 + 用户演示
```

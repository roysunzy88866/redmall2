# 设计任务:车载商店「RIDEMALL」车机端 UI 设计稿

## 这是什么
为一个**车载商店 demo** 设计车机端界面。**横屏 16:9,1920×1080,车载中控大屏 —— 不是手机竖屏!** 整体布局:左侧常驻竖向导航 + 右侧内容区。内部演示用,不接真实支付。

## 必须遵守的硬约束(不可改)
- **分辨率 1920×1080 横屏**,不可旋转,沉浸式(不显示系统状态栏)
- **左侧常驻导航**,固定 7 项,从上到下:推荐 / 车载用品 / 加油充电 / 户外旅行 / 3C数码 / 品质生活 /(最底)订单;当前页对应项高亮
- 货币写法 `¥39.00`(中文 ¥ + 两位小数)
- 全中文界面

## ⚠️ 关于下面的线框图(重要,先读)
每个屏都附了一张 ASCII 低保真线框。**它只表达「有哪些元素、各自在什么位置、谁和谁相邻」,不代表比例、间距、圆角、配色、字体等任何视觉**。请据它布局,但**视觉按下面的「视觉方向」自由发挥、做成精致设计稿**,不要照搬方框的等宽呆板样子。

## 视觉方向(空着的用你的专业判断,但风格要统一)
- **调性**:[待填,例:科技简约 / 高端 / 年轻活力]
- **明暗**:[待填,深色为主 / 浅色为主 —— 车机夜间使用多,深色常见]
- **主色**:[待填,例:蓝绿科技色 / 橙色暖调]
- **参考风格**:[待填,一句话最省事,例:像特斯拉车机 / 像 Apple Store App / 像小米商城]
- **品牌名**:RIDEMALL(占位,可保留)
- **字体**:[默认系统中文字体即可,有偏好再写]
